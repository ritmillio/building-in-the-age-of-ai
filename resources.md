# Resources: Building in the Age of AI

A curated reading and tool list for founders, product people and operators. Every link below was opened and checked on **2026-10-20**. Where a page redirected, the final URL is listed. Vendor pages change fast, so a link can move after that date.

Format: `[Title](url) — why it's useful (author/org)`

---

## 1. Start here (the 10 best first reads)

- [Building effective agents](https://www.anthropic.com/engineering/building-effective-agents) — The clearest map of "workflow vs agent" and the five core patterns; start simple, add autonomy only when it pays (Anthropic)
- [Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) — Why context is a finite "attention budget" and how to curate it; the core idea of this workshop (Anthropic Applied AI)
- [Getting started with AI: Good enough prompting](https://www.oneusefulthing.org/p/getting-started-with-ai-good-enough) — Non-technical, practical: treat the AI like a person you brief, then iterate (Ethan Mollick)
- [Centaurs and Cyborgs on the Jagged Frontier](https://www.oneusefulthing.org/p/centaurs-and-cyborgs-on-the-jagged) — Plain-language summary of the BCG study: big gains inside the frontier, worse results outside it (Ethan Mollick)
- [Andrej Karpathy: Software Is Changing (Again)](https://www.youtube.com/watch?v=LCEmiRjPEtQ) — "Software 3.0" talk at YC AI Startup School; how to think about building products on LLMs (Andrej Karpathy / Y Combinator)
- [Here's how I use LLMs to help me write code](https://simonwillison.net/2025/Mar/11/using-llms-for-code/) — Grounded, sceptical, hands-on habits for working with coding models (Simon Willison)
- [Best practices for Claude Code](https://code.claude.com/docs/en/best-practices) — Explore, plan, code, verify: the workflow that works for any coding agent (Anthropic)
- [Context Rot: How Increasing Input Tokens Impacts LLM Performance](https://www.trychroma.com/research/context-rot) — Evidence that more context makes models worse, even on easy tasks (Chroma Research)
- [Equipping agents for the real world with Agent Skills](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills) — Why "skills" (folders of instructions + scripts) are the next step after prompts (Anthropic)
- [The lethal trifecta for AI agents](https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/) — The one security idea every builder of agents must know (Simon Willison)

## 3. Context windows, context rot & context engineering

- [Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows) — Official definition, what counts toward the window, sizes per model, "context rot" named in the docs (Anthropic)
- [Models overview (Claude)](https://platform.claude.com/docs/en/about-claude/models/overview) — Current Claude models, context window and max output per model (Anthropic)
- [Models (OpenAI API)](https://developers.openai.com/api/docs/models) — Current GPT models with context window and output limits (OpenAI)
- [Gemini models](https://ai.google.dev/gemini-api/docs/models) — Current Gemini models and per-model limits (Google)
- [Long context (Gemini API)](https://ai.google.dev/gemini-api/docs/long-context) — Put the question last; multi-needle retrieval is weaker than single-needle (Google)
- [Context Rot](https://www.trychroma.com/research/context-rot) — 18 models tested; performance drops as input grows, even for simple retrieval (Hong, Troynikov, Huber / Chroma)
- [Lost in the Middle: How Language Models Use Long Contexts](https://arxiv.org/abs/2307.03172) — The original "U-shaped" finding: facts in the middle of a long prompt get missed (Liu et al., TACL)
- [NoLiMa: Long-Context Evaluation Beyond Literal Matching](https://arxiv.org/abs/2502.05167) — When the question doesn't share words with the answer, 11 of 13 models fall below 50% of baseline at 32K tokens (Modarressi et al., ICML 2025)
- [RULER: What's the Real Context Size of Your Long-Context Language Models?](https://arxiv.org/abs/2404.06654) — Advertised context length ≠ effective context length (Hsieh et al.)
- [Needle in a Haystack test](https://github.com/gkamradt/needle-in-a-haystack) — The original simple long-context retrieval test everyone cites (Greg Kamradt)
- [How Long Contexts Fail](https://www.dbreunig.com/2025/06/22/how-contexts-fail-and-how-to-fix-them.html) — Names the failure modes: poisoning, distraction, confusion, clash (Drew Breunig)
- [How to Fix Your Context](https://www.dbreunig.com/2025/06/26/how-to-fix-your-context.html) — The fixes: RAG, tool loadout, quarantine, pruning, summarisation, offloading (Drew Breunig)
- [Context engineering](https://simonwillison.net/2025/Jun/27/context-engineering/) — Why "context engineering" is a better term than "prompt engineering" (Simon Willison)
- [Context Engineering for Agents](https://www.langchain.com/blog/context-engineering-for-agents) — Write, select, compress, isolate: a taxonomy of techniques (LangChain)
- [Context Engineering for AI Agents: Lessons from Building Manus](https://manus.im/blog/Context-Engineering-for-AI-Agents-Lessons-from-Building-Manus) — Production lessons: KV-cache, file system as memory, keep errors in context (Manus)
- [Don't Build Multi-Agents](https://cognition.com/blog/dont-build-multi-agents) — The counter-argument: sub-agents lose shared context; share full traces (Cognition)
- [Compaction overview](https://platform.claude.com/docs/en/build-with-claude/compaction) — Server-side summarisation of old turns to keep long tasks inside the window (Anthropic)
- [Context editing](https://platform.claude.com/docs/en/build-with-claude/context-editing) — Automatically clear old tool results and thinking blocks (Anthropic)
- [Memory tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool) — Let an agent write notes to files and read them back next session (Anthropic)
- [Managing context on the Claude Developer Platform](https://claude.com/resources/articles/context-management) — Announcement of context editing + memory with the reasoning behind them (Anthropic)
- [Explore the context window (Claude Code)](https://code.claude.com/docs/en/context-window) — What fills Claude Code's context and how to inspect it (Anthropic)
- [How Claude remembers your project](https://code.claude.com/docs/en/memory) — CLAUDE.md / AGENTS.md / auto memory: persistent instructions across sessions (Anthropic)
- [AGENTS.md](https://agents.md) — The open, tool-neutral "README for agents" format used by Codex, Cursor and others (agents.md community)
- [Custom instructions with AGENTS.md (Codex)](https://learn.chatgpt.com/docs/agent-configuration/agents-md) — How OpenAI's Codex reads AGENTS.md files (OpenAI)
- [What are projects? (Claude)](https://support.claude.com/en/articles/9517075-what-are-projects) — Project knowledge + instructions; automatic RAG when knowledge gets large (Anthropic)
- [Use Claude's chat search and memory](https://support.claude.com/en/articles/11817273) — How Claude's memory and past-chat search work and where to switch them off (Anthropic)
- [How large is the context window on paid Claude plans?](https://support.claude.com/en/articles/8606394) — Context size in the Claude apps (not the API), and automatic summarisation (Anthropic)
- [Projects in ChatGPT](https://help.openai.com/en/articles/10169521-projects-in-chatgpt) — Files, instructions and project memory in ChatGPT (OpenAI)
- [Memory in ChatGPT](https://help.openai.com/en/articles/8590148-memory-faq) — Saved memories vs reference chat history, and how to manage them (OpenAI)
- [Gemini Apps limits & feature availability](https://support.google.com/gemini/answer/16275805) — Context window per Google AI plan in the Gemini app (Google)
